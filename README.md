# Leitor Inglês

Leitor de *graded readers* em inglês para e-readers Boox (Android, tela e-ink).

- Biblioteca em prateleiras por nível (A1–C2), com o progresso de cada livro.
- Leitura paginada, sem animações, com atualização completa da tela a cada N páginas e botões de página/volume.
- Toque numa palavra: tradução, definição, exemplo, imagem (Wikipédia/Wikimedia) e "Enviar para Vocabulário".
- Aba **Gramática**: os pontos gramaticais aparecem conforme você lê, em ordem de aprendizagem.
- Aba **Vocabulário**: Verbos, Expressões e Palavras.
- Botão **Adicionar livro**: gera o pedido para o Claude e importa o arquivo `.lib.json`.

Livros incluídos (B1): *Dracula*, *Moby Dick* e *The Red and the Black*.

O APK é gerado automaticamente pelo GitHub Actions a cada atualização e publicado em **Releases**.
O formato dos livros está em [docs/BOOK_FORMAT.md](docs/BOOK_FORMAT.md).
